📁 Hierarquia da UI

🔄 Lista Virtualizada

  • ⚡ Só renderiza itens visíveis
  • 📜 Plugin scrolla automaticamente
  • ⏳ Aguarda 3 frames por scroll
  • 🎯 Detecta classe CSS "selected"
  • 🚫 Deduplica por chave única
  • 🛡️ Máximo 300 scrolls (segurança)

📝 Extração de Texto

  • 🔍 Busca TextElement nas células
  • 🧹 Remove tags HTML (<color>)
  • 📊 Pula coluna 0 (checkbox)
  • ✂️ Escapa ; e " para CSV
  • 🔑 Chave: 3 primeiras colunas
  • 💾 UTF-8 encoding
