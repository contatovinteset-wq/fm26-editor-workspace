## FM26 BepInEx Plugin - Solução Final

### Problema
- `BaseUnityPlugin` não era encontrado (CS0246) - DLLs BepInEx 6 IL2CPP não expõem essa classe da forma esperada

### Solução Aplicada
- Plugin é classe plain com `[BepInPlugin]` attribute
- Usa `Logger.CreateLogSource("FM26CtrlP")` para logger
- `MonoBehaviour` separado (`UpdateRunner`) para loop Update
- Cria GameObject em runtime para rodar o MonoBehaviour

### Arquivos
- **Repo**: `https://github.com/contatovinteset-wq/fm26-editor-workspace`
- **Plugin**: `fm26-ctrlp-mod/FM26ExportPlugin.cs`
- **Csproj**: `fm26-ctrlp-mod/FM26CtrlPExport.csproj`
- **Commit final**: `a97a2d8`

### Configuração BepInEx
- TargetFramework: `netstandard2.1`
- Referências principais: BepInEx.Core.dll, 0Harmony.dll, Il2CppInterop.Runtime.dll
- UnityEngine: CoreModule, UnityEngine, InputLegacyModule
- Game: FMGame.dll, FM.UI.dll (interop)

- Ctrl+P: Chama `UpdateExportCurrentItemBinding` em carousels/tables encontrados
- F10: Lista tipos com "Export", "Carousel", "Table" no nome (debug)
