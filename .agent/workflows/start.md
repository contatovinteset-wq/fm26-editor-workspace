description: Inicialização do Contexto do Workspace
---

Ao iniciar uma nova sessão:

1. Leia as regras estritas globais e contexto em `.agent/rules/fm26-context.md` para restaurar nosso contexto técnico e de desenvolvimento.
2. Leia `.agent/rules/session-history.md` para compreender com maestria onde paramos, nossa arquitetura e nossos maiores desafios superados e os atuais.
3. Leia o repositório git desde a última compilação se existir (rode o comando `git log --oneline -10`) para certificar o que o autor codou até aqui na branch atual.
4. Apresente ao usuário, em português do Brasil, um resumo extremamente sucinto de **apenas 5 linhas** com o estado final captado do projeto considerando todas essas fontes.
5. Em seguida e na mesma mensagem, pergunte diretamente: "Qual é a tarefa desta sessão?".
