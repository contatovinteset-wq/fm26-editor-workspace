# Skin Minimalista Brasil v0.1 - FM26

## Instalação

### Método 1: Teste Rápido (Substituir arquivos originais)

**⚠️ FAÇA BACKUP ANTES!**

1. Feche o FM26
2. Navegue até a pasta de assets do FM26:
   - Windows: `C:\Arquivos de Programas\Steam\steamapps\common\Football Manager 2026\data\`
   - Linux: `~/.steam/steam/steamapps/common/Football Manager 2026/data/`
3. Faça backup da pasta `ui-backgrounds_assets_common`
4. Copie o conteúdo de `backgrounds-convertidos/Texture2D/` para substituir os arquivos originais
5. Inicie o FM26 e veja a nova skin!

### Método 2: Skin Mod (Recomendado)

1. Crie uma pasta em `Documents/Sports Interactive/Football Manager 2026/skins/MinimalistaBrasil/`
2. Copie a estrutura de pastas da skin
3. No jogo, vá em Preferências > Interface > Selecionar Skin

## Paleta de Cores

- **Cinza Escuro** `#1A1A1F` - Backgrounds principais
- **Cinza Médio** `#2D2D35` - Bordas e cards
- **Cinza Claro** `#404048` - Elementos de interface
- **Azul** `#0066CC` - Acentos primários
- **Amarelo** `#FFD700` - Destaques e estrelas
