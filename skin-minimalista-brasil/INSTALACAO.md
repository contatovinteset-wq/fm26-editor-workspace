# Skin Minimalista Brasil v0.1 - FM26

## Instalação

1. **Localização da pasta de skins do FM26:**
   - Windows: `Documents/Sports Interactive/Football Manager 2026/skins/`
   - Mac: `~/Documents/Sports Interactive/Football Manager 2026/skins/`
   - Linux: `~/.local/share/Steam/steamapps/compatdata/[APPID]/pfx/drive_c/users/[USER]/Documents/Sports Interactive/Football Manager 2026/skins/`

2. **Copiar a pasta `skin-minimalista-brasil` para o diretório de skins**

3. **No jogo:**
   - Ir em Preferences → Advanced → Interface
   - Desmarcar "Use caching to decrease page loading times"
   - Marcar "Reload skin when confirming changes in Preferences"
   - Selecionar "Minimalista Brasil" na lista de skins
   - Clicar "Confirm"

## Estrutura

```
skin-minimalista-brasil/
├── backgrounds-convertidos/   # 70 backgrounds com paleta BR
├── paleta.json               # Definição das cores
├── converter_skin_fast.py    # Script de conversão
└── INSTALACAO.md             # Este arquivo
```

## Paleta de Cores

- **Cinza Escuro** `#1A1A1F` - Backgrounds principais
- **Cinza Médio** `#2D2D35` - Bordas, separadores
- **Cinza Claro** `#404048` - Elementos de interface
- **Azul** `#0066CC` - Acentos primários
- **Amarelo Ouro** `#FFD700` - Acentos secundários
