Exporte jogadores selecionados para CSV com um simples atalho

Ctrl+P Iniciar exportação
F8 Re-escanear UI

📊 Fluxo de Execução

1
Localiza o elemento playertable na UI
2
Extrai headers de column-headers (pula coluna 0 = checkbox)
3
Inicia scroll do ScrollView para capturar linhas virtualizadas
4
Salva CSV em Documents/Sports Interactive/Football Manager 2026/

row

    └── ... demais colunas
