🐺 FM26 Player Export

Como exportar jogadores do Football Manager 26 para CSV

1
Problema

O Football Manager 26 não possui uma função nativa para exportar dados de jogadores para CSV.

O jogador precisa copiar os dados manualmente, o que é:

  • Lento — uma linha por vez
  • Impraticável — para centenas de jogadores
  • Propenso a erros — dados incompletos ou incorretos

Necessidade: exportar todos os jogadores selecionados de uma vez, em formato estruturado.

2
Hipótese

O FM26 é construído em Unity com UI Toolkit para interface.

Os dados exibidos na tabela de jogadores estão acessíveis via:

  • VisualElement — estrutura da UI
  • Label / TextElement — textos visíveis
  • ScrollView — container com scroll

Desafio: a tabela é virtualizada — só existem elementos visíveis na tela.

3
Alternativa de Solução

Criar um plugin BepInEx IL2CPP que:

  • Acessa a UI do jogo em tempo real
  • Navega pela árvore de VisualElement
  • Extrai texto de cada célula da tabela
  • Simula scroll para capturar linhas virtualizadas
  • Salva os dados em CSV
UI Unity → → Encontra tabela → → Captura linhas
↑→ Scroll → → Captura mais → → CSV
4
Proposta

FM26PlayerExport — Plugin BepInEx com as seguintes funcionalidades:

Hotkeys:

Ctrl+P Iniciar exportação
F8 Re-escanear UI

Fluxo de captura:

  • Localiza playertable na árvore UI
  • Extrai cabeçalhos de column-headers
  • Detecta linhas com classe virtualised-list__item--selected
  • Extrai texto de cada célula (incluindo estrelas/ratings)
  • Scrolla automaticamente para capturar mais linhas
  • Deduplica por hash do conteúdo completo

Proteções:

  • Limite de 5000 linhas por export
  • Para após 3 passos sem novos dados (stalled)
  • Máximo de 500 tentativas de scroll
  • Try-catch em todas as operações
5
Resultado

  • ✅ Captura de linhas selecionadas
  • ✅ Leitura de estrelas/ratings via classes CSS
  • ✅ Deduplicação robusta
  • ✅ Scroll automático para lista virtualizada
  • ✅ Proteção contra loops infinitos
  • ✅ Compatível com atualizações do jogo
6
Conclusão

O FM26PlayerExport resolve o problema de exportação de dados do Football Manager 26 de forma eficiente e confiável.

Pontos-chave:

  • Usa APIs públicas do Unity — não quebra com atualizações
  • Aborda a virtualização com scroll automático
  • Trata casos especiais (estrelas, células compostas)
  • Protege contra erros e loops infinitos

Resultado prático:

Com um simples Ctrl+P, o jogador exporta centenas de registros em segundos, diretamente para CSV, pronto para análise em Excel ou outras ferramentas.
